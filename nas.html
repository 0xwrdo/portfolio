Raspberry Pi NAS

A custom-built Network Attached Storage solution for automated local and remote backups. Runs headless 24/7.

Raspberry PiOpenMediaVaultSambarsyncAlways On

Setup

  • HardwareRaspberry Pi 4 with USB-attached HDDs in a custom enclosure with active cooling.
  • OS & SoftwareOpenMediaVault on top of Raspberry Pi OS for a clean NAS dashboard.
  • File SharingSamba shares for Windows/Mac/Linux access across the local network.
  • Backupsrsync cron jobs for automated incremental local and remote backups.
  • Remote AccessExposed selectively via Cloudflare Tunnel — no raw port forwarding.
