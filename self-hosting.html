Self-Hosting Infrastructure

Global web delivery via Cloudflare Tunnels and Nginx, hosted entirely on local Raspberry Pi hardware. No cloud bill.

Raspberry PiNginxCloudflare TunnelsLinuxZero Cloud Cost

How it works

🥧

Raspberry Pi Server

Runs headless Ubuntu Server in my room — web server, DNS resolver, and file share all in one box.

🌐

Cloudflare Tunnels

Outbound tunnel from the Pi to Cloudflare's edge, so no open inbound ports, no public IP needed.

⚙️

Nginx

Reverse proxy handles SSL termination, routing, and Gzip compression for every subdomain.
